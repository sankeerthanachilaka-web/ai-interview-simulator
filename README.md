# AI Interview Simulator 🎯

An AI-powered platform designed to help students practice technical interviews and improve their interview performance.

## 🌐 Live Demo
[Try the AI Interview Simulator](https://ai-interview-simulator-7-xhks.onrender.com)

## 💻 Source Code
[View this project on GitHub](https://github.com/sankeerthanachilaka-web/ai-interview-simulator)

## ✨ Features
- Resume-based interview questions
- AI-generated technical questions
- AI answer evaluation and scoring
- Weak-topic tracking and performance history
- Voice and video interview features
- Personalized interview preparation resources

## 🛠️ Technologies
- Python
- Flask
- SQLite and SQLAlchemy
- HTML, CSS, JavaScript and Bootstrap
- Groq AI and Whisper

## 🎯 Project Goal
To provide students with a personalized interview practice experience that helps them identify weak areas and improve through feedback.

## 🤖 Development Note
AI tools were used to assist with ideation, coding support, debugging, and learning unfamiliar technologies as part of this hands-on project.
